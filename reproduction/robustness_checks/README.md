Run python reproduce_extension.py to replay all 20 grouped partitions, the primary geographic comparison and distance-constrained donor retrieval. Requirements: NumPy, SciPy, pandas. Results are written to rerun/. Inputs contain derived representations and full original-transport distances, not raw discharge. The supplied raw original-transport matrix is reused, not recomputed by this replay. Epsilon diagnostics are separate and are not evidence of full-cohort parameter robustness.

Run python reproduce_epsilon.py for converged 0.05/0.1 reduced-cohort calculations. epsilon_failure.json archives the unsuccessful 0.01 attempt; this configuration is not silently assigned a score. The final rerun script skips the known unsuccessful 0.01 setting. epsilon_histograms.npz contains the derived joint histograms.
